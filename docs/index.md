## What You'll Learn

This roadmap covers six core areas, designed to be followed in sequence:

- **Math Foundations** -- Linear algebra, calculus, and probability & statistics for ML
- **Python for ML** -- NumPy, Pandas, visualization, and Scikit-learn essentials
- **Core ML** -- Supervised and unsupervised learning, model evaluation, feature engineering
- **Deep Learning** -- Neural networks, CNNs, RNNs, transformers, and frameworks
- **MLOps** -- Project lifecycle, deployment, monitoring, and system design
- **Research Skills** -- Reading papers, reproducing results, and staying current

## Prerequisites

This roadmap assumes working knowledge of Python programming. If you are new to Python, consider completing an introductory Python course before starting.

## How to Use This Site

Follow the tabs in order from left to right. Each tab represents a stage in the learning path. Within each tab, work through the pages from top to bottom. The sequence is designed so that each topic builds on the ones before it.

Use the search bar to find specific topics, and toggle dark mode with the icon in the header.
