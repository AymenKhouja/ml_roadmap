**In docs/javascripts/progress.js**, add these functions and update the subscribe callback:

1. **isIndexPage()** -- detect if current page is a section index. Check if `getPageKey()` ends with `/index` or if the URL path has only one segment after the site root (section-level page). Alternatively, check for a `.section-progress` placeholder or just always attempt to render (no-op if no topic links found).

2. **resolvePageKey(href)** -- given a relative href from an index page link (e.g., `supervised-learning/` or `../core-ml/supervised-learning/`), resolve it to the same page key format used by `getPageKey()`. Extract the section and page slugs to form `section/page`. Handle relative paths by combining with the current page's section.

3. **createProgressBar(percent, checked, total)** -- returns a DOM element:
   ```html
   <span class="progress-bar-container">
     <span class="progress-bar-track">
       <span class="progress-bar-fill" style="width: {percent}%"></span>
     </span>
     <span class="progress-bar-label">{percent}% ({checked}/{total})</span>
   </span>
   ```

4. **injectSectionTotal(container, checked, total)** -- creates or updates a `.section-progress` element at the top of the content area (before the first heading or after the info admonition). Shows: `Section progress: {percent}% ({checked}/{total} items)` with a wider progress bar (300px or full-width). Remove any existing `.section-progress` element first to prevent duplication on instant-loading.

5. **renderProgressBars()** -- main function:
   - Call `getProgress()` to get all stored data
   - Query `.md-content` for the content area
   - Remove any previously injected `.progress-bar-container` and `.section-progress` elements (prevent duplication)
   - Find all links in the content area (`a[href]`)
   - For each link, try to resolve its href to a page key using `resolvePageKey()`
   - Look up that page key in the progress data
   - If found and `total > 0`, create a progress bar and append it after the link (or to the link's parent `li` or `p` element)
   - Track running totals for section-level progress
   - If any progress data was found, inject a section total at the top

6. **Update document$.subscribe** to call both `initCheckboxes()` and `renderProgressBars()`.
